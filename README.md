# MedFlow - AI-Powered EHR & Healthcare Workflow Management

MedFlow is a modern, modular Electronic Health Record (EHR) and clinical workflow management system designed to streamline OPD/IPD operations, patient records, digital prescriptions, and health analytics for medical facilities.

---

## 🚀 Key Features

- **Smart Patient Records (EHR):** Digitalization of patient history, consultations, and diagnosis.
- **OPD & IPD Queue Management:** Automated patient registration and workflow routing.
- **AI Clinical Summaries:** Automated clinical record summarization powered by Groq API.
- **Digital Prescriptions & Lab Integration:** Seamless connection between doctors, pharmacy, and laboratory modules.
- **Role-Based Access Control:** Secure dashboards for Doctors, Receptionists, Pharmacists, and Admins.

---

## 🛠️ Tech Stack

- **Frontend:** React.js, Tailwind CSS
- **Backend:** Node.js, Express.js
- **Database & Cloud:** Supabase 
- **AI Integration:** Groq API and LLM Models
